# 王者荣耀现代卡池

卡册 ID：`hok-modern-s1`；名称：王者荣耀现代图鉴；封面：甄姬。共 128 张，接入现有全局抽卡池、碎片兑换、卡册进度、分档领奖、全套领奖和后台卡册奖励列表。

| 稀有度 | 张数 | 集齐该档奖励 |
| --- | ---: | ---: |
| 传说稀有 | 10 | 7000 积分 |
| 传说 | 18 | 4000 积分 |
| 史诗 | 24 | 2400 积分 |
| 稀有 | 32 | 1400 积分 |
| 普通 | 44 | 800 积分 |
| 全套 | 128 | 22000 积分 |

各档奖励和全套奖励分别领取一次；六项累计 37600 积分。

单抽、五连抽的揭晓动画与验收结果见 [抽卡动画](card-draw-animation.md)。

## 图片与目录

源图来自 `output/imagegen/hok-modern-pool-20261025/成品/`。西施使用腿部修正后的 v2 成品。

- 原图：`public/images/王者现代/稀有度/角色名.png`，1024 × 1536；与来源 PNG 字节一致。
- 高清图：`public/images-optimized/large/王者现代/稀有度/角色名.webp`，1024 × 1536。
- 缩略图：`public/images-optimized/thumb/王者现代/稀有度/角色名.webp`，480 × 720。

卡牌 ID 遵循现有格式 `hok-modern-s1-稀有度-角色名`。前端角色分配位于 [hok-modern.ts](../src/lib/cards/hok-modern.ts)，后端分配位于 [hok_modern.go](../backend/internal/cards/hok_modern.go)，全套与分档积分同步配置在前端和后端卡册目录中。
