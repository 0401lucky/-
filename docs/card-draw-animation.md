# 抽卡动画

适用于全局卡池的单抽和五连抽；王者现代篇的卡牌与奖励分配见 [卡池说明](hok-modern-card-pool.md)。

## 展示与交互

- 抽卡请求与舞台蓄光同时开始；单抽准备高清图，五连抽准备缩略图。等待图片解码最多 1600 毫秒，离开页面时取消等待。
- 卡牌错落入场，随后逐张侧转展开，展示完整卡面、稀有度、角色名称，以及新卡或重复卡碎片。
- 每轮只为最高稀有度触发一组彩屑，史诗及以上启用，最多 64 个粒子。自有画布限制为单抽 620 × 460、五连抽 880 × 460，并随屏幕尺寸缩小。
- 柔光使用透明度变化；揭晓期间暂停主舞台的背景动画。彩屑使用同步清理，避免画布移除和窗口缩放交错时残留监听器。
- “立即揭晓”取消后续自动翻牌计时器；“再抽一次”保留本轮抽数，并遵守冷却和次数限制。
- Esc 在揭晓中显示全部结果，完成后收起弹层；Tab 焦点留在弹层内，完成后聚焦“收下卡牌”。减少动态效果时直接显示结果并关闭彩屑。
