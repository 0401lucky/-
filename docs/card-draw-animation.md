# 抽卡动画

适用于全局卡池的单抽和五连抽；王者现代篇的卡牌与奖励分配见 [卡池说明](hok-modern-card-pool.md)。

## 展示与交互

- 采用 A「流星预告」方向：蓝色流星对应普通 / 稀有，紫色对应史诗，金色对应传说；传说稀有的流星先呈金色，落地前转为彩虹。五连增加伴随流星。
- 流星落地后按服务端结果顺序逐张展示大卡，普通 / 稀有 / 史诗 / 传说 / 传说稀有分别停留 850 / 950 / 1300 / 1800 / 2300 毫秒；五连最后显示完整汇总。单抽在大卡入场完成后即可收下。
- 点击卡面、背景或“下一张”，以及右方向键，可加速逐张亮相；每张至少展示 380 毫秒，避免连续点击跳过多张。“跳过动画”直接展示全部结果，并取消后续动画与彩屑。
- 抽卡请求与舞台蓄光同时开始；单抽准备高清图，五连准备高清图和汇总缩略图，相同图片去重解码。等待最多 1600 毫秒，离开页面时取消等待。
- 五档稀有度使用各自的外框、角标、中文等级与光效；传说使用金色流光，传说稀有使用彩虹镭射。底部名牌覆盖原卡图统一的装饰星星，保留新卡或重复卡碎片信息；鼠标移动时卡面轻微倾斜。
- 每轮只为最高稀有度触发一组彩屑，史诗及以上启用，最多 64 个粒子。自有画布限制为单抽 620 × 460、五连抽 880 × 460，并随屏幕尺寸缩小。
- 揭晓期间暂停主舞台的背景动画。彩屑使用同步清理，避免画布移除和窗口缩放交错时残留监听器。
- “再抽一次”保留本轮抽数，并遵守冷却、余额和卡池开放限制；消耗显示为本轮抽数 × 当前卡池单抽消耗。
- Esc 在揭晓中显示全部结果，完成后收起弹层；Tab 焦点留在弹层内，完成后聚焦“收下卡牌”。减少动态效果时直接显示结果并关闭彩屑。
