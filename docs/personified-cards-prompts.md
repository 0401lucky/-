# 站内元素拟人卡池 — 生图提示词集

- **卡池主题**：把本站的功能模块与小游戏拟人化为二次元角色
- **卡池规模**：26 张
- **目标模型**：gpt-image-2
- **画风统一策略**：固定风格锚 + 稀有度分层构图
- **角色性别**：混合

---

## 一、使用说明

### 1.1 怎么用这份文档

每张卡的「完整提示词」是一段**可直接整段复制**的中文自然语言描述，已经把风格锚、构图层级、角色设定、配色全部揉进去了，不需要再拼接。

gpt-image-2 是自然语言理解型模型，**不要**给它 Danbooru tag 串、权重括号 `(xxx:1.3)`、或负向提示词——这些写法对它无效甚至有害。它吃的是「像跟画师说话一样」的完整句子。

### 1.2 出图参数建议

- **画幅**：竖版 3:4（与现有动物卡、塔罗卡的卡面比例一致）
- **一次一张**：不要让它一次画多个角色，拟人卡需要单人聚焦
- **重绘策略**：同一段提示词跑 3–4 次挑最好的，比反复改提示词更省时间

### 1.3 风格锚（已内嵌进每段提示词，此处仅作说明）

> 现代日系二次元角色立绘，赛璐璐平涂上色，线条干净利落，色彩明快饱和，柔和的动画质感光影，五官精致有神，整体观感干净不脏，适合作为收藏卡牌的正面立绘。

**每次生成都必须让这段风格描述原样出现**，这是 26 张卡看起来像「同一套」的唯一保证。如果你中途想换风格，必须 26 张全部重跑，不要混用。

### 1.4 稀有度分层构图规则

| 稀有度 | 张数 | 取景 | 姿态 | 背景 | 光效 |
|---|---|---|---|---|---|
| 普通 | 9 | 胸像至半身 | 正面站立，安静 | 纯色柔和渐变 | 无 |
| 稀有 | 7 | 半身 | 轻微侧身，手持道具 | 简单几何图案 | 轻微 |
| 史诗 | 5 | 四分之三身 | 明确动作 | 场景化环境 | 光斑与粒子 |
| 传说 | 3 | 全身 | 强动态，衣摆飞扬 | 简洁环境，不铺满 | 单一主光源，克制 |
| 传说稀有 | 2 | 全身 | 戏剧性构图，俯仰视角 | 宏大场景 + 几何法阵 | 极强，整体发光 |

这个梯度是为了让玩家**抽到高稀有度时一眼能看出来**——不靠边框，靠画面本身的信息密度。

> **传说档为什么要克制**：首轮试图时把传说档写成了「强烈光效 + 华丽画面」，结果模型把它做到了和传说稀有同等的饱满程度，两档在视觉上分不出来。满屏光效是传说稀有的专属待遇，传说档必须主动让位。

### 1.5 全局禁令：不要可读中文

gpt-image-2 生成中文字符**基本不可靠**——首轮出图中法阵、账簿、数字流上的汉字全是编造的假字，放大即露馅。相比之下它的英文和阿拉伯数字是准确的。

因此每段提示词末尾都统一追加了这句：

> 画面中不要出现任何可读的中文字符；所有符号、纹样、代码流一律使用抽象几何刻痕、二进制数字或阿拉伯数字来表现。

少数卡面**需要**特定字符可读（2048 的数字、登顶者胸前的「1」），这些是阿拉伯数字，不在禁令范围内。

### 1.6 配色去重

高稀有度的 5 张里有 3 张会自然滑向金色（金紫 / 金绿 / 金红），摆在一起会腻。已在提示词中强调：

- 持钥者：金 + 深紫，**金色主导**（唯一允许的满金画面）
- 计数官：**墨绿主导**，金色只作点缀
- 登顶者：猩红与炭黑主导，金色仅用于奖台与数字

## 八、出图完成后的接入步骤

图生成好之后，按现有卡池的约定放置和登记即可：

### 8.1 文件放置

```
public/images/拟人卡/传说稀有/兑换码.png
public/images/拟人卡/传说稀有/积分.png
public/images/拟人卡/传说/抽卡.png
...
public/images/拟人卡/普通/管理后台.png
```

目录名用**稀有度中文名**：`传说稀有` / `传说` / `史诗` / `稀有` / `普通`，与 `动物2`、`塔罗` 两套的组织方式完全一致。

### 8.2 生成优化图

现有卡池都有 `images-optimized/thumb` 与 `images-optimized/large` 两档 webp。新卡池需要走同样的优化流程（脚本在 `scripts/` 下，接入时确认具体命令）。

### 8.3 登记卡池

在 `src/lib/cards/config.ts` 中：

1. `ALBUMS` 数组追加一项，`id` 建议 `persona-s1`，`season` 填「特别篇」或「第一季」
2. 按 `animalS2Cards` 的写法新增五组卡名常量数组 + 一个 `getPersonaImagePath()` 路径函数
3. 把新卡组并入末尾的 `CARDS` 数组

卡背复用 `/images/通用1/` 下的五张稀有度通用卡背，**不需要另做**。

### 8.4 奖励数值

`tierRewards` 与 `reward` 参照现有梯度设定。26 张的规模介于动物 S1（20 张）与动物 S2（40 张）之间，取值建议落在两者之间。
